# Privacy Policy / حریم خصوصی

## Persian Layout Fix Extension / افزونه مبدل صفحه‌کلید فارسی

### Data Collection / جمع‌آوری داده
**English:** This extension does NOT collect any personal information, track your browsing activity, send data to external servers, or store any text you convert.

**فارسی:** این افزونه هیچ اطلاعات شخصی جمع‌آوری نمی‌کند، فعالیت مرور شما را ردیابی نمی‌کند، داده‌ای به سرورهای خارجی ارسال نمی‌کند و هیچ متنی را ذخیره نمی‌کند.

### Local Processing / پردازش محلی
**English:** All text conversion happens locally in your browser. No text leaves your computer.

**فارسی:** تمام تبدیل‌های متن به صورت محلی در مرورگر شما انجام می‌شود. هیچ متنی کامپیوتر شما را ترک نمی‌کند.

### Permissions Explanation / توضیح مجوزها
- **activeTab**: Required to access currently active tab for text conversion
- **<all_urls>**: Required to work on all websites where you might type text

- **activeTab**: برای دسترسی به تب فعال برای تبدیل متن لازم است
- **<all_urls>**: برای کارکرد در تمام وبسایت‌هایی که ممکن است متن تایپ کنید لازم است

### Open Source / متن‌باز
**English:** This extension is open source. You can review the code to verify no data collection.

**فارسی:** این افزونه متن‌باز است. می‌توانید کد را بررسی کنید تا عدم جمع‌آوری داده را تأیید کنید.
